## Landscape overview

The market clusters into three adjacent jobs: **remember everything** (Pieces), **carry an agent session into another tool** (`continues`), and **plan/review many agent tasks** (Vibe Kanban). CapsStack's whitespace is narrower: it marks an away interval and creates a human-readable return brief without resuming the source session or requiring a new orchestration system.

## Strategic takeaways

1. **Own human re-entry, not generic memory.** “What happened while I was away?” is clearer and more defensible than “never lose context.”
2. **Avoid accidental resume semantics.** `continues` already owns cross-agent continuation; CapsStack's deliberate no-resume boundary can be a trust advantage.
3. **Make review readiness the outcome.** Vibe Kanban and public research both show planning/review—not raw generation—as the bottleneck.
4. **Stay small until willingness to pay is proven.** Vibe Kanban's shutdown is a direct warning that high usage and GitHub popularity may coexist with weak monetization.
5. **Privacy needs concrete contrast.** CapsStack can credibly contrast an explicit interval and selected sources with broad always-on capture, while still disclosing that the chosen summarizer may process content remotely.

## Gaps and opportunities

- **Time-to-first-confident-action:** no competitor scanned appears to make this the primary outcome metric.
- **Review triage:** add or emphasize files/areas changed, unverified claims, blockers, and recommended checks.
- **Zero-dashboard behavior:** the physical trigger plus notification can differentiate from boards and memory search.
- **Provider-neutral but non-executing:** support heterogeneous tools without launching the next agent.
- **Business-model validation:** test paid value around repeat re-entry and saved review time before team features or subscriptions.

## Threats

- Coding agents can add built-in end-of-task summaries, notifications, and handoff buttons.
- Cross-agent tools can add a “brief only” mode.
- macOS automation utilities can reproduce the trigger while agent plugins generate summaries.
- Caps Lock is memorable but may cap adoption among remapped-keyboard and multilingual users.
