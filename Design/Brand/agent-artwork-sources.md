# Agent artwork sources

CapsStack bundles these marks locally so the agent picker works offline. The files are used
for product identification and are not intended to imply endorsement or affiliation.

| Resource | Official source | Notes |
| --- | --- | --- |
| `AgentCodex.svg` | [OpenAI brand](https://openai.com/brand/) and [OpenAI Logos 2025](https://cdn.openai.com/brand/OpenAI-Logos-2025.zip) | Codex uses OpenAI's official Blossom mark because the public Codex repository does not publish a separate product symbol. |
| `AgentClaudeCode.svg` | [Claude favicon](https://claude.com/favicon.svg) and [Claude Code repository](https://github.com/anthropics/claude-code) | Official Claude mark. |
| `AgentOpenCode.svg` | [OpenCode brand resources](https://opencode.ai/brand) | Official light-square SVG mark. |
| `AgentPi.svg` | [Pi logo](https://pi.dev/logo-auto.svg) and [Pi website repository](https://github.com/earendil-works/pi-website) | Official responsive logo SVG. |
| `AgentGitHubCopilot.svg` | [GitHub Copilot brand](https://brand.github.com/brand-identity/copilot) and [Microsoft Codicons](https://github.com/microsoft/vscode-codicons/blob/main/src/icons/copilot.svg) | Official Copilot product icon from the maintained Codicons source. |

The existing PNG artwork for Kilo, Goose, Qwen Code, Continue, and Gemini remains unchanged.
