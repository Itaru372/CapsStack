# CapsStack UI capture set

アプリ本体のUIを、設定の各ページ・選択状態・詳細設定・確認画面・履歴表示・セットアップ・退席前メモ・アプリ情報まで保存した参照用画像です。

- `01-`: 収集元（利用可能な収集元、未検出エージェントの展開、一覧下部）
- `02-`: 要約担当（利用可能／未検出CLIの各選択状態、推論強度、フォールバック）
- `03-08-`: 一般、通知、ホットキー、データ管理、詳細設定、検索
- `07-`: 8種類のCLI詳細、接続テスト中／成功、詳細設定の上下端
- `10-`: 履歴のデモ表示、日別選択、本文下部、空月、収集注意、コピー／書き出し／削除UI
- `20-`: セットアップのステップ1〜4
- `30-`: 退席前メモ
- `40-`: CapsStack情報
- `50-menubar-only/`: CapsStackがアクティブな状態のアプリメニューバー部分のみ（CapsStack、ファイル、編集、表示、履歴、設定、ウインドウ、ヘルプ）

画像はアプリ画面中心の参照用です。`50-menubar-only/` はデスクトップ全体や背景アプリを含めず、CapsStackのメニューバーだけを切り出しています。
